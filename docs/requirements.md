# **Raspberry Pi 卓上ウェザーステーション＆スマートクロック 初期要件定義書**

# **1\. プロジェクト概要・目的**

Raspberry Pi 4および専用タッチディスプレイ（解像度 800×480）を活用し、SwitchBot スマートデイリーステーション風の卓上情報端末を構築します。

過度な汎用フレームワーク（MagicMirror²等）のブラックボックス化を避け、**React / Tailwind CSS**による軽量・高レスポンスなWebフロントエンドと**Chromiumキオスクモード**を採用して、800×480に最適化されたスマートクロック兼環境ダッシュボードを実現します。

---

# **2\. システム構成・動作環境**

## **2.1 ハードウェア要件**

- **SBC**: Raspberry Pi 4 Model B
- **ディスプレイ**: 7インチ前後のタッチスクリーン（解像度: 800 × 480、横向き運用）
- **ネットワーク**: Wi-Fi または 有線LAN（インターネット常時接続）
- **（オプション）室内環境センサー**: I2C温湿度気圧センサー（BME280等）または既存スマートホーム機器（SwitchBot温湿度計 BLE/API連携）

## **2.2 ソフトウェアスタック**

- **OS**: Ubuntu (64-bit)
- **ランタイム**: Node.js (v20+) / Bun
- **フロントエンド**: React \+ TypeScript \+ Tailwind CSS (Vite環境)
- **表示シェル**: Chromium Browser（`--kiosk` モード）
- **画面制御**: X11 / Wayland 環境下での自動起動スクリプト (`systemd` または autostart)

---

# **3\. 画面レイアウト要件 (解像度: 800×480 固定)**

画面全体を `800px × 480px` の固定ビューポートとして構成し、縦横スクロールバーおよびOS UIを完全に排除します。

| 領域                   | サイズ        | 主要構成要素                                                                                  |
| :--------------------- | :------------ | :-------------------------------------------------------------------------------------------- |
| **メイン表示領域**     | 800px × 438px | **\[左ペイン\]** 時計・現在天気**\[中央ペイン\]** 環境メトリクス**\[右ペイン\]** 週間天気予報 |
| **下部ステータスバー** | 800px × 42px  | Googleカレンダー予定 / 最終更新時刻 / ナイトモード切替                                        |

## **3.1 各ペインの詳細要件**

1. **左ペイン（時計 & 当日天気概要）**
   - リアルタイムデジタル時計（`hh:mm:ss` 表示、1秒ごとに更新）
   - 和暦/西暦、曜日表示
   - 当日の現在の天気アイコン、現在気温、最高/最低気温、降水確率
2. **中央ペイン（環境・各種メトリクス）**
   - 室内環境タイル（温度、湿度、快適度ステータス）
   - 屋外環境タイル（温度、湿度）
   - 環境サブ情報（UVインデックス、風速、気圧、日の出/日の入り時刻）
3. **右ペイン（週間予報）**
   - 5〜7日先までの天気アイコン、最高/最低気温リスト
   - タップで対象日の時間帯別予報モーダルを展開可能
4. **下部ステータスバー**
   - 次の予定サマリー（タイトル・開始時刻）
   - データ最終更新時刻およびステータスインジケーター
   - ナイトモード（低輝度・ダーク配色）トグルスイッチ

# **4\. 機能要件**

## **4.1 データ連携・取得**

- **天気・気象データ**
  - 一次データソース: Open-Meteo API（認証キー不要）
  - 取得間隔: 15〜30分ごとの自動フェッチ（ブラウザ側バックグラウンド更新）
  - 取得項目: 現在気温、体感温度、天候コード、週間気温推移、UV指数、風速、日の出・日の入り
- **予定・カレンダー連携**
  - データソース: Googleカレンダー（非公開iCal URL または Google Calendar API）
  - 直近1〜2件のイベントを抽出して表示
- **室内環境データ（フェーズ別実装）**
  - _Phase 1_: モックデータまたはOpen-Meteoの屋外データのみで稼働
  - _Phase 2_: Raspberry Pi GPIO接続センサー（BME280等）またはBLEアドバタイズ受信によるSwitchBot温湿度計の値反映

## **4.2 タッチ操作インターフェース**

- **週間予報カードタップ**: 時間別予報モーダル表示
- **室内環境カードタップ**: 過去24時間の温湿度推移グラフ（任意拡張）
- **ナイトモードボタンタップ**: ダークトーン/低刺激カラーパレットへの即時切り替え

## **4.3 端末常設・運用制御**

- **キオスク自動起動**: OS起動後、デスクトップ表示を介さずフルスクリーンでChromiumを立ち上げ
- **マウスカーソル非表示**: `unclutter` 等を用いたカーソルの自動非表示
- **画面焼き付き・輝度制御**:
  - 深夜時間帯（例: 23:00〜07:00）の自動減光または画面オフ
  - `sysfs` (`/sys/class/backlight/...`) 経由でのバックライト輝度制御スクリプト連携
