# UIレビュー課題と改善仕様書

本書は、提供されたプロトタイプ画面（800×480 固定ビューポート）におけるUIレイアウト崩れ、データ表示不備、および改善仕様をまとめた資料です。

---

## 1. 検出された課題一覧

| No    | 領域                 | 現象・課題                                                      | 原因                                                             | 改善方針                                                             |
| :---- | :------------------- | :-------------------------------------------------------------- | :--------------------------------------------------------------- | :------------------------------------------------------------------- |
| **1** | 左ペイン（時計）     | 「秒」(`02`) が改行されて右下に落ちている                       | 横幅指定がタイトで折り返しが発生している                         | `whitespace-nowrap` を付与し、時:分とベースライン（下揃え）を統一    |
| **2** | 左ペイン（天気）     | 当日の最高/最低気温、体感温度、降水確率が `--` 表示になっている | 当日予報データのバインドおよびフォールバック処理の不備           | Open-Meteoの `daily[0]` および `apparent_temperature` を正しく紐付け |
| **3** | 中央ペイン（室内）   | 室内湿度の見出しが「水分」になっている                          | ラベル定義の誤り                                                 | SwitchBot標準に準拠し「**湿度**」に修正                              |
| **4** | 中央ペイン（環境）   | 「紫外線指数指数 5」と単語が重複している                        | 「紫外線指数」+「指数」のラベル結合ミス                          | 「**UV指数**」または「**紫外線**」に統一                             |

## 2. 詳細な改善仕様

### 2.1 時計カード（左ペイン上部）

- **フォント・整列**:
  - 時:分: `font-mono text-5xl font-bold`
  - 秒: `font-mono text-2xl font-semibold text-muted-foreground`
  - 秒を時:分と同じ行のベースラインに配置（`flex items-baseline`）し、絶対に改行させない（`shrink-0 whitespace-nowrap`）。

### 2.2 当日天気カード（左ペイン下部）

- **現在気温**: `font-mono text-4xl font-extrabold`
- **体感気温**: `体感 26℃` のように実数値をバインド
- **最高 / 最低 / 降水確率**: `↑ 27° / ↓ 20°`、`☂ 69%` を下部バーにすっきり配置

### 2.3 室内外環境タイル（中央ペイン）

- **室内環境**:
  - 「温度 22.8℃」
  - 「湿度 48%」（「水分」から「湿度」へ修正）
- **サブメトリクス**:
  - 「UV指数 5」（重複排除）
  - 「風速 2.3m/s」
  - 「日の出 05:45」
  - 「日の入 17:08」

### 2.4 週間天気予報（右ペイン）

- **レイアウト保証**:
  - 日付・曜日: 幅 60px 固定 (`10/14 水`)
  - 天気アイコン & 降水確率: 幅 64px (`[Icon] ☂ 69%`)
  - 気温: 幅 64px (`27° / 20°`)
  - すべての要素に `whitespace-nowrap` を適用し、度記号やパーセント記号が次行に落ちる現象を完全に防止

### 2.5 ステータスバー（下部）

- **最終更新**: データフェッチ成功時の現在時刻を `16:49 更新` のように表示
- **インジケーター**: 緑のパルスLED表示
