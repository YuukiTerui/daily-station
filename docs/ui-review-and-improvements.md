# UIレビュー課題と改善仕様書

本書は、提供されたプロトタイプ画面（800×480 固定ビューポート）におけるUIレイアウト崩れ、データ表示不備、およびSwitchBot公式UIに準拠した画面リニューアル仕様をまとめた資料です。

---

## 1. 検出された課題一覧（第1次レビュー）

| No    | 領域                 | 現象・課題                                                      | 原因                                                             | 改善方針                                                             |
| :---- | :------------------- | :-------------------------------------------------------------- | :--------------------------------------------------------------- | :------------------------------------------------------------------- |
| **1** | 左ペイン（時計）     | 「秒」(`02`) が改行されて右下に落ちている                       | 横幅指定がタイトで折り返しが発生している                         | `whitespace-nowrap` を付与し、時:分とベースライン（下揃え）を統一    |
| **2** | 左ペイン（天気）     | 当日の最高/最低気温、体感温度、降水確率が `--` 表示になっている | 当日予報データのバインドおよびフォールバック処理の不備           | Open-Meteoの `daily[0]` および `apparent_temperature` を正しく紐付け |
| **3** | 中央ペイン（室内）   | 室内湿度の見出しが「水分」になっている                          | ラベル定義の誤り                                                 | SwitchBot標準に準拠し「**湿度**」に修正                              |
| **4** | 中央ペイン（環境）   | 「紫外線指数指数 5」と単語が重複している                        | 「紫外線指数」+「指数」のラベル結合ミス                          | 「**UV指数**」または「**紫外線**」に統一                             |
| **5** | 右ペイン（週間予報） | 降水確率の `%` および気温の `°`（度記号）が縦落ちしている       | リストアイテム内の横幅不足と flex 折り返し                       | 各列に十分な固定幅と `whitespace-nowrap` を指定し1行表示を保証       |
| **6** | ステータスバー       | データ更新時刻が `--:--更新` のまま                             | 初期ロード後の更新タイムスタンプのフォーマットまたはバインド漏れ | フェッチ完了時刻を即時反映し、`HH:mm 更新` を表示                    |

## 2. SwitchBot公式UIに準拠したリニューアル仕様（第2次改修）

公式 SwitchBot スマートデイリーステーションのUI構成を分析し、より視認性と実用性を高めたレイアウトへ刷新しました。

```
+-----------------------------------------------------------------------------+
| [左ペイン: 270px]           | [中央ペイン: 290px]         | [右ペイン: 240px]         |
| ・日付 (2026-10-13 火曜日)  | 【空気質タイル】            | 【週間天気予報】          |
| ・デジタル時計 (16:55:00)   |  AQI: 30 / PM2.5 / 花粉     |  今日 [晴れ] 18%  23/17℃  |
| ・天気サマリー (晴れ 23/17℃) | --------------------------- |  水   [雨]   69%  27/20℃  |
| 【屋内外温湿度】            | 【気象詳細リスト】          |  木   [曇]   25%  23/17℃  |
|  屋外: 22.8℃  76%          |  風速: 2.3 m/s              |  金   [晴]    4%  24/17℃  |
|  室内: 22.8℃  48% 😊       |  風向: 北東 72°             |  土   [雨]   12%  23/17℃  |
| --------------------------- |  UV指数: 5                  |  日   [晴]    1%  22/14℃  |
|  日の出 05:45 | 日没 17:08  |  降水確率: 18% / 視程 / 気圧|  月   [曇]   37%  25/17℃  |
+-----------------------------------------------------------------------------+
| 下部ステータスバー: 次の予定 / 16:55 更新 / ナイトモード切替                |
+-----------------------------------------------------------------------------+
```

### 2.1 左ペイン（時計 ＋ 今日の天気 ＋ 屋内外温湿度）

1. **デジタル時計**:
   - 日付を最上部に配置（`2026-10-13 火曜日`）
   - 太字フォントによる時:分 (`16:55`) と、ベースライン揃えの秒表示 (`:00`)
2. **今日天気 & 屋内外温湿度の統合カード**:
   - **屋外**: 🌡 `22.8℃`　💧 `76%`
   - **室内**: 🌡 `22.8℃`　💧 `48%`　**😊（快適度フェイスアイコン）**
   - **日の出・日の入**: 最下部に `🌅 05:45 | 🌇 17:08` を配置

### 2.2 中央ペイン（空気質タイル ＋ 気象詳細リスト）

1. **空気質タイル（上部）**:
   - Open-Meteo Air Quality API と連携
   - `AQI 30 (良好)` / `PM2.5 12µg/m³` / `花粉 少ない` の3マスグリッド
2. **気象詳細リスト（下部）**:
   - 1行ずつアイコン＋ラベル＋数値を整然と表示
   - `風速` (`2.3 m/s`) / `風向` (`東北東 72°`) / `UV指数` (`5`) / `降水確率` (`18%`) / `視程` (`>10km`) / `気圧` (`1014 hPa`)

### 2.3 右ペイン（週間予報）

- 先頭行に「今日」をハイライト表示
- 明日以降の曜日（水、木、金、土、日、月）のリスト
- `アイコン` + `降水確率` + `曜日` + `最高/最低気温` を 1 行に収め、文字落ちを完全排除

### 2.4 下部ステータスバー

- 次の予定タイトル・開始時刻
- データ最終更新時刻（緑のパルスLED、HH:mm 形式）
- ナイトモード即時トグルスイッチ
